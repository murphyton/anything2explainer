# 五主题标尺静帧

每主题 4 帧，全部出自同一项目（CSAPP 第 1 章，csapp01）的实际渲染，作为「按指定主题创建」的风格标尺：

| 帧 | 内容 | 看什么 |
|---|---|---|
| `f_0030.png` | 片头封面 | 封面版式（kicker + 主题字体大标题 + 渐变分割线 + 副标）+ 幕底 |
| `f_1950.png` | 章节卡 | 正文版式（左上 kicker+标题+细线，右侧大章号数据卡） |
| `f_8620.png` | 正文镜头 | 幕底常驻态 + HUD 胶囊 + 进度条 + 层级图形的主色化 |
| `f_13500.png` | 片尾 | 收尾回扣 + 结尾构图 |

主题与 `src/themes/tokens.json` 一一对应：`purple-dots`（默认）/ `nobel` / `book` / `ai` / `stem`。
注意 ai 的粒子流与 stem 的网格生长是动态效果，静态帧只能看构图与配色；动态验证渲 15s 样片（`scripts/preview.sh 15`）。
